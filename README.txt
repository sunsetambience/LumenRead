LumenRead 10 — Android/PWA
===========================

ЧТО ВНУТРИ
index.html — интерфейс и движок чтения.
manifest.json, sw.js, icon-*.png — комплект устанавливаемого PWA.

КАК ЗАПУСТИТЬ НА АНДРОИД
1. Для проверки можно открыть index.html в Chrome на телефоне,
   но функции PWA и офлайн-кэш требуют запуска с сайта.
2. Чтобы установить как приложение, разместите ВСЕ файлы папки
   на HTTPS-сервере (например, GitHub Pages).
3. Откройте адрес в Chrome Android → меню ⋮ →
   «Установить приложение» или «Добавить на главный экран».
4. Загрузите книгу через «☰ Меню» → «3D-Полка книг».

MINDMAP
Издательские страницы и оглавление автоматически отсекаются по
типовым признакам. Если граница определена неверно, откройте
в оригинале (100%) первую страницу сюжета, затем выберите
MindMap → «С текущей страницы». Кнопка «Автоопределение»
сбрасывает ручную настройку. Есть режим без спойлеров.

ОЗВУЧКА
Встроено 6 РАЗНЫХ профилей высоты голоса и темпа:
3 мужских и 3 женских по назначению. Различные реальные
голоса зависят от установленных в Android TTS-синтезаторов.
Если устройство не предоставляет шесть отдельных мужских и
женских голосов, приложение не сможет создать их из воздуха:
профили будут использовать доступный голос с изменением
высоты и темпа. В настройках озвучки можно назначить
конкретный системный голос каждой кнопке.

ОГРАНИЧЕНИЯ
Это PWA, а НЕ готовый APK. Поддержка EPUB/DOCX/CBZ зависит
от JSZip, PDF — от PDF.js, которые первоначально загружаются
через интернет (CDN); после удачного кэширования на сайте
часть функций может работать офлайн. TXT/FB2/HTML/MD не
нуждаются в этих внешних библиотеках. CBR (RAR) не поддержан.
MindMap и конспекты — локальная эвристика, не облачный ИИ.
Сверяйте важные детали с текстом автора.

СОВЕТ
Для обновления не удаляйте данные сайта: книги хранятся
локально в IndexedDB браузера. Не очищайте данные Chrome
без резервной копии собственных книг.
